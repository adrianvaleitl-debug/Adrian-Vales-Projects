NOW AVAILABLE / GITMESSAGE V1

GitMessage is officially released.

The stable public release is live on web and Windows. Download the desktop app or open it in your browser.

OFFICIAL LAUNCH · V1 · BUILD 4.0.259PUBLIC RELEASE

GitMessage brings real-time conversations to web and Windows, with one account across both platforms. Create an account, customise your profile, chat live, build communities and make one-to-one calls.

Features: real-time direct messages and history; conversation search; five-minute message grouping and context actions; profile pictures, display names, previews and clickable bio links; servers and text channels; supported image/video sharing; one-to-one voice/video calls; joining calls without camera or microphone permission; responsive web and Windows apps; light/dark themes; automatic stable desktop updates.

Calling note: calls are currently one-to-one. Camera and microphone are optional to join, but local audio/video is not sent without permission.

Reverse Marketplace

A buyer-led marketplace where customers post what they need and sellers compete with offers. The planned MVP includes buyer and seller accounts, request listings, offer comparison, messaging, dashboards, seller ratings and reviews. Monetisation is planned through a 5–10% commission on completed transactions.

MVP planning stage — the repository currently contains the product specification; the functional marketplace is not yet implemented.

06 / HOW I WORK

Ideas, built properly.

A little more about the thinking behind the software, the details I care about and what I want each project to feel like.

Useful first.

I look for everyday problems where a small, well-made tool can save time, remove friction or make something easier to understand.

Designed to feel clear.

Simple navigation, readable layouts and sensible defaults matter just as much as the feature list.

Built to keep improving.

Projects are developed in versions, with fixes and improvements shaped by real use rather than adding complexity for its own sake.

Independent projects.

I handle the ideas, product direction, websites and development across my own small collection of software.

Easy to get started.

Each project should have a clear home, a straightforward download route and a place to find updates or source code.

Room to experiment.

Not every idea needs to become a huge platform. Small focused tools can still make a meaningful difference.
