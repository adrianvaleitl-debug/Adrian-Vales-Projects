# Adrian Vale — Official Portfolio

**Live website:** https://adrianvaleitl-debug.github.io/Adrian-Vales-Projects/

The central portfolio for Adrian Vale's independent software projects. The portfolio currently features only three projects: MarketView, GitMessage and Reverse.

## Current projects

### MarketView
A market research and risk-planning desktop workspace built with React, TypeScript and Tauri. It includes a watchlist, technical scanner, alerts, position-sizing tools, a trade journal and configurable links to external trading platforms. MarketView does not connect to a brokerage account or place trades.

- [GitHub repository](https://github.com/adrianvaleitl-debug/MarketView)
- [Latest releases and Windows downloads](https://github.com/adrianvaleitl-debug/MarketView/releases)

### GitMessage
A real-time messaging application available on the web and Windows. Features include direct messaging, searchable conversations, public profiles, server spaces and text channels, supported media sharing, one-to-one voice/video calls and automatic stable desktop updates.

- [Open the web app](https://adrianvaleitl-debug.github.io/GitMessage/)
- [GitHub repository](https://github.com/adrianvaleitl-debug/GitMessage)
- [Latest Windows release](https://github.com/adrianvaleitl-debug/GitMessage/releases/latest)

Calling is currently one-to-one. Group calls are not available.

### Reverse
Reverse Marketplace is a planned buyer-led marketplace: buyers publish requests with budgets, images and deadlines, then sellers compete by submitting offers. The MVP specification includes buyer/seller accounts, request browsing, offer comparison, messaging, dashboards, seller ratings, reviews and a proposed 5–10% commission on completed transactions. The repository currently documents the specification; the functional application has not yet been implemented.

- [GitHub repository](https://github.com/adrianvaleitl-debug/Reverse)
